# Tax Navigator

Інформаційний податковий навігатор для українців у Польщі з крос-бордерним
доходом: укр ФОП, B2B-оффер, віддалена українська зарплата.

**Живий продукт:** [tax-navigator-red.vercel.app](https://tax-navigator-red.vercel.app)
· [джерела чисел](https://tax-navigator-red.vercel.app/uk/poland/sources)
· [токени дизайну](https://tax-navigator-red.vercel.app/tokens)

## Проблема

Українець у Польщі не може без консультації за 200–300 zł відповісти на три
питання: чи я податковий резидент Польщі, яка форма вигідна і легальна
(укр ФОП / JDG / інкубатор / UoP), що і куди подавати в обох країнах.
Безкоштовна інформація існує, але фрагментована й ніколи не персоналізована.

## Продукт

Анкета з ~10 питань дає вердикт резидентства і порівняння шести сценаріїв із
діапазонами «чистими». Усе рахується на клієнті: сервера, бази й реєстрації
немає, дані нікуди не йдуть.

Продукт **не радить**. Він показує варіанти, діапазони й посилання на
першоджерело кожного числа — рішення лишається за людиною. Це не стиль, а
правило, яке перевіряється тестами й рев'ю.

Платний план дій (PDF) і підписка на моніторинг змін правил — після того, як
попит підтвердиться. Деталі продукту: [docs/PROJECT.md](docs/PROJECT.md).

## Як це побудовано

Соло-проєкт, написаний із Claude Code як основним інструментом розробки.
Інженерний контур навколо коду:

- **Числа як дані.** Кожна ставка живе в `app/lib/rules/rules.2026.json` із
  посиланням на першоджерело й датою звірки. У UI немає жодної цифри з памʼяті.
- **Межі шарів.** `rules → calc → adapters → presentation`, односторонньо;
  порушення ловить граф імпортів у `npm run verify`.
- **Ворота замість обіцянок.** Хуки перевіряють коміти, гілки й секрети;
  ізольовані кейси у восьми наборах — [docs/TEAM-CONTOUR.md](docs/TEAM-CONTOUR.md).
- **Візуальна регресія.** 40 еталонів екранів знімаються на CI у світлій і темній
  темі, на десктопі й на 375px.
- **Два допоміжні інструменти:** збір питань із Telegram за запитом (команда на
  VPS, без розкладу) і місячна звірка правил проти першоджерел.

Тести: `npm test` (431) і `npm run test:ui` (27). Повна перевірка: `npm run verify`.

## Стек

Next.js, TypeScript, mobile-first, українська локалізація. Деплой на Vercel,
фонові воркери на VPS.

## Два фонові інструменти

- **Автозвірка правил** (`rules-verify`, GitHub Actions за розкладом): кожне з 26 правил
  звіряється з першоджерелом — сторінкою, змінами акта в ELI Сейму чи редакцією на
  zakon.rada. Збіг — бот-PR з новою датою звірки; розбіжність чи змінений закон — issue
  і чернетка PR від агента. Мерджить людина. Розклад — [sad.md §7](docs/features/rules-change-monitor/sad.md).
- **Колектор питань** (`tg-assistant`): збір із Telegram-чатів лише за запитом,
  розмітка — Claude ([research/tg-assistant/WEEKLY.md](research/tg-assistant/WEEKLY.md)).
