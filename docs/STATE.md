**Контекст (preflight, 2026-08-04).**

- **Держкалькулятор існує лише для складок — і він скриптується.**
  `zus.pl/firmy/przedsiebiorco-przeczytaj-wazne/kalkulator-skladki-zdrowotnej` —
  Liferay-портлет: форма POST-иться з `curl`, підтримує `periodYear=2026`.
  Прогнав п'ять запитів проти наших параметрів, збіг до копійки: liniowy дохід
  15 000 → 735,00; ryczałt прихід 50k / 180k / 400k → 498,35 / 830,58 / 1 495,04;
  skala дохід 1 000 → 432,54 (мінімум). Тобто половина G2 може бути **відтворюваною
  автоматично**, а не «Mike клікає в браузері».
- **Держкалькулятора для PIT немає.** На `podatki.gov.pl` лишились лише
  `kalkulator-taryfowy`, `odsetek` і `walut`; `kalkulator-wynagrodzeń` Polskiego
  Ładu віддає 404. EVIDENCE §7 і PROJECT §G2 писались із припущення, що він є.

  ручним виведенням із норми з посиланням на артикул, як уже зроблено для

  рішення, а не допуск для арифметики.
- **Мережі в тестах немає.** Прогін проти `zus.pl` — окремим скриптом, який пише
  фікстуру з відповіддю держави + `fetched_at` + URL; `npm test` звіряється з
  фікстурою офлайн.
