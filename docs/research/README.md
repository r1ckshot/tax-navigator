# Розвідка планової сесії 2026-10

Чотири звіти, які зібрали дослідницькі агенти для планової сесії
([ROADMAP.md](../ROADMAP.md)). Це **розвідка, а не джерела чисел**: кожна
ставка, поріг чи дата перед тим, як потрапити в продукт або в текст для людей,
проходить звичайний ланцюг [evidence-numbers](../../.claude/rules/evidence-numbers.md)
(`/scaffold-rule`, першоджерело, `verified_at`). Пошук ішов лише через WebSearch,
сайти агенти не відкривали; невивірене в самих звітах позначене.

| Файл | Що в ньому | Хто читає |
|---|---|---|

| [2026-10-competitors-seo.md](2026-10-competitors-seo.md) | Конкуренти (міжкраїнні калькулятори, україномовні гайди, PL-калькулятори), хто ранжується за українськими запитами | теми 3.1 і 6.1 |
| [2026-10-communities.md](2026-10-communities.md) | Telegram, Facebook, Reddit, медіа: Польща детально, інші країни точково; правила реклами | тема 5.2, шаблон країни |
| [2026-10-payments-legal.md](2026-10-payments-legal.md) | Nierejestrowana для іноземця, VAT і межа «doradztwo», MoR проти Stripe, юридичні тексти, GDPR, Telegram ToS | теми 1.3 і 4.1 |

Звіти не оновлюються заднім числом. Коли тема звіряє факт із першоджерелом,
результат іде в [EVIDENCE.md](../EVIDENCE.md) або в артефакти фічі, а не сюди.
