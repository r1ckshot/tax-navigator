# ROADMAP — від поточного продукту до Європи

План, який виконується командою «Begin». Тут порядок, а не календар: дат і темпу
немає свідомо. Рішення, на яких план стоїть, — [DECISIONS.md](DECISIONS.md), запис
2026-10-01; розвідка — [research/](research/README.md).

## Протокол «Begin»

Mike пише «Begin». Сесія:

1. Бере першу сесію зі станом `[ ]` у таблицях нижче, зверху вниз. Тема «П»
   («Поза чергою») іде першою, якщо спрацював її тригер. Сесія з «Чекає: …»
   пропускається, доки умову не виконано, — і про це один рядок у підсумку.
2. Відкриває її файл у [sessions/](sessions/). Файл із позначкою «чернетка» спершу
   звіряє з STATE, DECISIONS і результатами попередніх сесій і уточнює — у тому ж
   коміті, без питань.
3. Preflight за [.claude/rules/preflight.md](../.claude/rules/preflight.md). Блокер,
   який знімає лише Mike, — одразу, готовим блоком, а не посеред роботи.
4. Гілка теми: перша сесія теми створює її від `master`, наступні продовжують ту
   саму (`git checkout <гілка> && git pull`).
5. Виконує кроки, викликає названі агенти й скіли. Питань у чаті не ставить, крім
   кроків, які фізично робить лише Mike (вони названі у файлі сесії розділом
   «Крок Mike»).
6. Сам перевіряє «Готово коли»: кожен пункт — командою з виводом або фактом.
7. Позначає сесію `[x]` тут, оновлює STATE.md (і BACKLOG, якщо зачеплено).
8. Одним повідомленням показує список файлів і просить дозвіл на коміт і пуш.
   Перша сесія теми після пушу відкриває чернетку PR. Остання — версія (якщо тема
   видима ззовні), `gh pr ready`, мердж: Claude запускає `gh pr merge`, Mike
   підтверджує промпт дозволу (на GitHub він не мерджить).
9. Закінчує трьома рядками: що зроблено, що закомічено, наступна сесія з моделлю й
   effort.

## Правила плану

- **Один PR на тему.** Тема — заголовок «Тема N.N»; сесій у ній може бути кілька.
  Правило й версія — [CLAUDE.md](../CLAUDE.md) §Pull requests.
- **Глибина артефактів** — рубрика CLAUDE.md; розмір названо в кожній темі.
- **Моделі** ([SESSIONS-GUIDE.md](SESSIONS-GUIDE.md)): Opus — архітектура й
  складний код; Sonnet — рутинна збірка; Fable — звірка законодавства і тексти з
  правовими твердженнями.
- **Агенти-дослідники** — Sonnet, ліміт пошуків у промпті, звіт пишеться у файл
  по ходу. Чотири дослідники на Opus без ліміту 2026-09-29 вичерпали ліміт сесії,
  не записавши жодного звіту.
- **Скоуп.** Нове поза цим планом іде через планову сесію, а не мовчки в поточну
  тему (OPEN-RISKS §3).
