## Мета

Анкета і результат виглядають і рухаються як преміум-продукт. Результат стає
дашбордом. Анімації не сповільнюють сторінку й вимикаються для тих, хто просить
менше руху.

## Кроки

1. Анкета: переходи між кроками (View Transitions API або CSS), прогрес у новій
   системі.
2. Результат-дашборд: вердикт, порівняльна таблиця, картки, акордеони з
   анімацією розкриття; числа діапазонів «набігають» лише візуально — значення
   завжди з `calc/`.
3. Мікровзаємодії: натискання, фокус, скелетони там, де щось вантажиться.
4. `prefers-reduced-motion`: усе стає миттєвим. Без зсувів макета (CLS).
5. Бібліотеку анімацій (Motion) підключати, лише якщо CSS не вистачило; тоді
   рядок у DECISIONS, і пакет живе тільки в presentation (межі — `npm run test:arch`).
6. Product-safety: анімація й колір не виділяють «найкращий» варіант.
