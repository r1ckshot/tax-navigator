## Мета

Сайт готовий до індексації, а нова сторінка-відповідь створюється одним файлом
змісту: числа на ній беруться з правил, джерела стоять унизу, є кнопка в анкету з
уже заповненими відповідями. Видно, звідки приходять люди.

## Кроки

1. Розмір S: короткий бриф і PRD у `docs/features/seo/`.
2. Metadata на кожній сторінці; `sitemap.xml` генерується; `robots.txt`; hreflang
   (`uk` + `x-default`); canonical від базової адреси з env.
3. Аналітика без cookie (Vercel Web Analytics): не бачить відповідей анкети.
   README і SPEC переписати точно — що збирається і що ні; рядок у DECISIONS.
4. Шаблон `/uk/poland/<slug>`: де живе текст (файли змісту поза `.tsx`); вставка
   числа за `rule_id` через `calc/`; блок джерел; кнопка в анкету з передзаповненням;
   місце під гайд (приховане до теми 4.1).
5. Guard-тести: кожне число на сторінці змісту — з правила; кожна сторінка є в
   sitemap.
6. Одна демонстраційна сторінка, щоб шаблон пройшов увесь шлях.
