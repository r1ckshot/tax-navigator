2. Зміст гайда не потрапляє в HTML чи клієнтський бандл до перевірки ключа — тест

4. Юридичні тексти: regulamin, політика приватності (Tally, аналітика, LS як
   обробник чи продавець), повідомлення про відмову від права відступлення для
   цифрового контенту, якщо LS цього не покриває; шаблон таблиці продажів для
   nierejestrowana (для Mike, поза репо).
5. GDPR листа очікування: договір обробки даних з Tally (art. 28) і коротке
   повідомлення art. 13 на самій формі ([research](../research/2026-10-payments-legal.md) §5).
6. Документи, які перестають бути правдою з появою сервера: SPEC.md non-goal 3,
   ARCHITECTURE.md (де в шарах живе серверний маршрут), README («сервера немає»).
