# 0001 — Normalize then compare numeric values for diff detection

- **Status:** Accepted
- **Date:** 2026-08-06
- **Deciders:** Mike + Claude (architecture-design, Socratic walk)

## Context

AC-04/AC-05 вимагають, щоб diff-детектор відрізняв косметичну відмінність
(форматування) від змістовної зміни (інше число після нормалізації). PRD
§8 називає це відкритим питанням: точний алгоритм нормалізації не
зафіксовано, лише поведінка (AC-04/05). §7 KPI ставить ціль ≤1
хибнопозитив на цикл — без чіткої стратегії порівняння цей KPI
недосяжний навмання.

## Decision drivers

- AC-04/AC-05 — обидва стани мають існувати окремо, не змішуватись.
- §7 KPI «Хибнопозитивні спрацювання ≤1 на цикл».
- §1 Топ-3 якість «Accuracy».
- CONTEXT.md: «дрейф» ≠ «зміна правила» — та сама дисципліна різних станів,
  перенесена в diff-логіку.

## Considered options

1. **Нормалізація → порівняння чисел** — парсити число з тексту джерела
   (пробіли/кома-крапка/zł, зайві нулі), потім порівнювати числове значення
   з матрицею.
2. **Raw string diff** — порівнювати текст дослівно, без нормалізації.
3. **Семантичний парсер під кожен тип норми** (% / zł / діапазон) окремо —
   найточніше, але окремий парсер на кожен `rule_id`-тип.

## Decision outcome

**Обрано:** Опція 1. Нормалізація числа — найменша робота, що вже закриває
AC-04/AC-05 і має шанс влучити в KPI ≤1 хибнопозитив; Опція 3 точніша, але
її обсяг парсерів не виправданий на M-розмірі фічі (можна дозріти до неї
пізніше, якщо KPI не витримає — це і є критерій зупинки v1-шару з PRD §7).

## Consequences

**Positive**
- Один спільний алгоритм нормалізації для всіх записів — не N окремих парсерів.
- Прямо тестується: еталонні пари (сирий текст джерела → очікуване число) як
  анти-регрес.

**Negative**
- Едж-кейси форматування, яких немає в еталонних тестах (нова форма запису
  джерелом), можуть спершу дати хибний «розбіжність» — KPI ловить це, не
  алгоритм заздалегідь.
- Не розрізняє тип норми (% vs zł) — покладається на те, що `rules.2026.json`
  вже зберігає значення в порівнянній формі.

**Neutral**
- Якщо KPI ≤1 хибнопозитив не витримається за 4 цикли (критерій зупинки
  §7 PRD), наступний крок — Опція 3 для проблемних типів норм, не переписка
  з нуля.
